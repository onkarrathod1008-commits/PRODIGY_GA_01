# PRODIGY_GA_01 – Text Generation with GPT-2

This project demonstrates text generation using the GPT-2 pretrained language model from Hugging Face.

## Objective
To generate coherent and contextually relevant text based on a user-provided prompt using a transformer-based model.

## Description
In this project, a GPT-2 model is loaded from the Hugging Face Transformers library and used for text generation.  
A simple web-based frontend is created using Gradio, allowing users to input a text prompt and receive generated output in real time.

## Tech Stack
- Python
- Hugging Face Transformers
- GPT-2
- Gradio
- Google Colab

## Features
- Text generation using GPT-2
- Simple and interactive frontend using Gradio
- Runs directly on Google Colab without local setup

## How to Run
1. Open the notebook in Google Colab  
2. Run all cells sequentially  
3. Open the Gradio public link generated  
4. Enter a prompt and generate text  

## Output
The model generates human-like text that follows the context of the input prompt.

## Limitation
- Uses a pretrained GPT-2 model without extensive fine-tuning
- Limited context length due to model constraints
